# Assets APK V13 — catégories, morphologies et branding

Cette version étend l'intégration visuelle officielle NBA 2K HQ 1.1.3 commencée en V12.

## Intégré dans l'interface

- Icônes officielles des 6 catégories sur les sections Badges.
- Icônes officielles des 6 catégories sur les panneaux Attributs.
- Artwork officiel de header de catégorie en filigrane dans les panneaux Attributs.
- Logo NBA 2K27 officiel + marque Player Builder dans le header principal.
- Galerie des 11 Body Types officiels sous la section Morphologie.

## Important — Body Types

Les 11 Body Types sont présentés comme visuels de référence uniquement. Ils ne modifient pas les caps, les attributs, le GNR ou les contraintes du build, car aucune règle APK vérifiée n'établit actuellement un tel effet.
